# 🎟️ VibePass Event Booking & OTT Explorer Platform

This repository contains a premium Event Booking and OTT (Over-the-Top) Streaming content explorer platform built on **Next.js**, styled with modern vanilla CSS, and backed by a serverless database schema.

---

## 🚀 Getting Started

1.  **Configure Environment Variables**:
    Make sure you have your `.env.local` set up correctly with variables for Database URL, Nodemailer (SMTP), and Stripe API keys.

2.  **Install Dependencies**:
    ```bash
    npm install
    ```

3.  **Run the Development Server**:
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
